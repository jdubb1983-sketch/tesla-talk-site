Privacy policy

This policy covers the Tesla Talk uploader, a private tool the Tesla Talk channel owner uses to publish videos to their own YouTube channel.

What data the app accesses

With the channel owner's permission, the app uses YouTube API Services to upload videos, captions and thumbnails, add videos to playlists, change a video's visibility, and read basic channel details (the channel name) for the owner's own channel. It does not access any other user's Google or YouTube data.

How the data is used and stored

The access permission (an OAuth refresh token) is stored only as an encrypted secret in the owner's private GitHub repository and is used only to publish the owner's own videos. No Google user data is sold, shared with third parties, or used for advertising.

Deleting data and revoking access

The owner can revoke access at any time at myaccount.google.com/permissions and delete the stored secret from the GitHub repository.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
